# Nuya – 多租戶餐飲點餐與營運管理模板

## 產品定位
Nuya 是一套專為餐飲店、咖啡店、飲品店、連鎖餐飲品牌與多店經營者設計的線上點餐與營運管理模板。它不只是前台點餐頁面，而是一套完整的數位餐飲營運系統，涵蓋顧客點餐、訂單管理、店內營運、品牌設定、菜單管理、分店管理、即時訂單更新與平台管理功能。

這套模板最大的優勢，是能讓每一家店都擁有自己的專屬網站與後台，同時由一個統一平台集中管理。對店家而言，這代表：快速開店、低成本上線、減少繁瑣操作、提升點餐效率、提升客戶體驗與訂單處理效率。

## 一、為什麼這套模板值得選擇

### 1. 直接可用，適合餐飲業快速上線

- 可直接拿來做品牌網站與外送/內用/自取線上訂餐入口

### 2. 一套系統，支援多店與多品牌經營
- 每間店都有獨立網站與獨立後台
- 共享平台底層系統，降低架構與維護成本
- 適合發展多品牌、多分店、多區域營運模式

### 3. 兼顧顧客體驗與店家效率
- 顧客可快速瀏覽菜單、加入購物車、選擇餐點選項、完成結帳
- 店家可即時查看新訂單、處理製作狀態、追蹤訂單完成與營收
- 具備追蹤訂單編號與電話查詢功能，提升售後和顧客服務效率

### 4. 真正適合商業部署的系統架構
- 使用 Next.js + TypeScript + Prisma + PostgreSQL
- 支援多租戶資料隔離與安全權限控制，並提供信箱驗證與密碼重設流程
- 可部署到 Vercel 等雲端平台，適合實際營運

## 二、核心功能總覽

### 1. 多租戶分店系統（Multi-Tenant）
- 每家店都有自己的專屬網址，例如 `yourdomain.com/{shop-slug}`
- 每個租戶擁有自己的資料、菜單、分店、訂單與後台
- 透過平台層集中管理所有店家，降低系統複雜度

### 2. 自助註冊與快速開店
- 店家可直接在平台註冊新店
- 系統支援商店名稱、自動生成網址 slug、第一個分店建立
- 店家登入後可直接進入後台建立菜單、時間、品牌資訊和分店資料
- 註冊信箱提供驗證信與忘記密碼/重設密碼流程，帳號安全有保障

### 3. 後台管理系統（店家端）
- 儀表板：查看今日訂單、營收、月營收趨勢、熱門商品
- 新店開通導覽清單：首次登入會顯示待完成項目（Logo、菜單分類、商品、分店資訊），完成後自動消失，幫助新店家快速上手
- 訂單看板：分辨 pending / completed 狀態
- 廚房顯示看板：專為廚房螢幕設計的大字體待處理訂單畫面，等待超過 10 / 20 分鐘會自動變色提醒，避免漏單或出餐延遲
- 菜單管理：新增、編輯、刪除菜色與分類
- 商品圖片上傳：支援品牌形象與菜品視覺呈現
- 時間段管理：設定營業時間與可預訂時段
- 例外關店日期：設置特殊休息日、節假日與停業日期
- 店鋪設定：品牌名稱、Logo、主色調、聯絡資訊
- 分店橫幅照片：每間分店可上傳自己的門市照片，並直接在後台裁切成最適合的比例，取代單一品牌色塊，讓每家分店在顧客點餐頁面上更有辨識度
- 一鍵複製專屬網址：後台頂部隨時可一鍵複製店家自己的點餐網址，方便貼到社群、LINE 或店內看板

### 4. 菜單與商品管理
- 支援分類管理（例如 主食、飲品、甜點、套餐）
- 每筆商品可設定價格、庫存狀態及是否上架
- 可設定商品圖片與品牌風格
- 支援多種加購選項與客製化條件，例如：
  - 大/中/小尺寸
  - 辣度選擇
  - 加購項目
  - 甜度、冰度、加料選擇
- 每個選項都可設定價格差異與最少/最多選擇限制

### 5. 訂單管理功能
- 新訂單自動顯示於待處理區
- 支援內用、外帶、外送等不同餐飲結帳型態
- 訂單資訊完整：顧客姓名、電話、餐點、加購選項、總額、付款方式、備註
- 可直接標記為完成或取消
- 提供列印廚房單功能，方便後場製作
- 廚房顯示看板：大螢幕專用的大字體待處理訂單畫面，等待超過 10 / 20 分鐘自動變色提醒
- 可依訂單編號、日期、電話或狀態進行篩選和查詢

### 6. 客戶點餐體驗
- 顧客可自由選擇分店、用餐型態與下單方式
- 流程簡單：瀏覽菜單 → 加入購物車 → 選項 → 結帳 → 確認訂單
- 提供訂單追蹤頁面，顧客可依訂單編號與電話查詢狀態
- 支援即時更新：顧客狀態頁面自動刷新，訂單狀態會同步更新

### 7. 即時更新與通知功能
- 新訂單到達時可觸發通知
- 店家後台會顯示新訂單警示與提示音
- 訂單狀態更新、菜單修改、時間段調整等資訊會自動同步
- 無需手動重新整理頁面，提升營運效率

### 8. 雙語支援（繁體中文 / English）
- 整體平台支援繁體中文與英文切換
- 顧客端、店家端、平台後台全部支援雙語
- 適合跨語言顧客群與國際化商業場景

### 9. 平台管理者後台
- 平台擁有者可管理所有租戶店家
- 可搜尋店家、查看訂單數、分店數、註冊日期與聯絡資訊
- 可暫停/啟用店家
- 可永久刪除店家與其資料
- 提供更高層級的營運控制與風險管理
